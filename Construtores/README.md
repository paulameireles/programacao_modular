# Construtores

## O que é um construtor?
Construtor, como a própria palavra diz, faz a construção do objeto, inicializa os atributos dando valores iniciais para criarmos o objeto funcional com todas aquelas caracteristicas.

## Como reconhecer um construtor 
Podemos reconhecer um construtor pelo próprio nome dele, que é igual ao nome da classe com primeira letra maiúscula e também não existe retorno, nem void.

## Para que serve o this?
Como a maioria das coisas em programação são autoexplicativa, o this se refere ao próprio objeto, então this.nome é o nome deste objeto, e não o parâmetro que chegou.

Por exemplo: Temos dois Joãos numa sala de aula, usar o this é meio que apontar para um dos joãos e falar esse joao aqui que tem tal coisa.

## Posso ter mais de um construtor na mesma classe?
Pode sim! Todos têm o mesmo nome (o da classe), o que muda são os parâmetros.

E como o Java sabe qual irá usar? 
Pelos parâmetros, o que vai dentro do parênteses. A regra é que eles podem ter o mesmo nome mas não podem ter a mesma lista de parâmetros senão o java não saberia qual escolher.
