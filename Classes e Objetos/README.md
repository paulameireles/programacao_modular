# Classes e Objetos 

## O que é uma classe?

Pense numa forma de bolo:
A classe seria a forma, ela define como o bolo vai ser porém não é um bolo, com 1 forma voce faz vários bolos e todos os bolos são independentes.

## O que é um objeto? 

voltando no bolo, o objeto seria o bolo já pronto, criado e independente.

## O que são atributos e métodos? 

Imagine um cachorro:

A raça, nome, idade, cor são coisas que ela TÊM, logo são atributos.

Coisas que ela FAZ são ditas como métodos, como latir(); comer(); dormir();.
